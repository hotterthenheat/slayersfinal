# Company marks

Where these came from, so nobody has to guess later.

**Source:** [Simple Icons](https://simpleicons.org) — the SVG files are
released under **CC0 1.0 Universal** (public domain dedication). No
attribution is required to use, modify or redistribute them; this note
exists for provenance, not obligation.

**What was changed:** each file carries its brand's official colour in the
root `fill`, rather than the bare monochrome path Simple Icons ships.
Near-black marks are flipped to white so they do not vanish on the dark
canvas. CC0 permits modification.

**Trademarks are not covered by CC0.** The glyphs depict registered
trademarks belonging to their owners, and Simple Icons says so explicitly.
Slayer uses them *nominatively* — to identify the company a row of market
data is about — which is the same use every broker, screener and terminal
makes of them. Do not use them to imply endorsement, partnership, or that
a company is a customer.

**Adding a name:** drop `{TICKER}.svg` in this folder. `CompanyLogo.tsx`
finds it by filename and falls back to a house monogram tile when there is
no file, so nothing has to change in code and nothing breaks in the
meantime.

**Currently carried (17):** AAPL, AMD, AMZN, AVGO, BA, BAC, CAT, CRM, GE,
GOOGL, GS, JPM, META, NFLX, NVDA, TSLA, WMT.
